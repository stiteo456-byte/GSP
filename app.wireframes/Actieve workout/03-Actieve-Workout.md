# 03 — Actieve Workout

## Wireframe
```text
┌─────────────────────────────┐
│ ← Workout          3 / 8   │
│                             │
│       BENCH PRESS           │
│                             │
│      [ oefening beeld ]     │
│                             │
│ Set 1     60 kg    10 reps  │
│ Set 2     60 kg    10 reps  │
│ Set 3     60 kg     8 reps  │
│                             │
│ Gewicht [ 60 ]              │
│ Reps     [ 10 ]             │
│                             │
│       [ ✓ SET VOLTOOID ]    │
│                             │
│      Rust: 01:24            │
│                             │
```

## Styling
- Focused full-screen UI
- Grote touch targets
- Hoog contrast
- Grote invoervelden voor gewicht/reps
- Prominente primaire CTA
- Rusttimer duidelijk zichtbaar
- Minimale navigatie
- Progress indicator bovenaan

## Must-have
- Naam oefening
- Foto/video
- Sets
- Reps
- Gewicht
- Set voltooien
- Rusttimer
- Workoutprogressie
- Pauzeren
- Volgende/vorige oefening
- Workout beëindigen
- Workout automatisch opslaan
